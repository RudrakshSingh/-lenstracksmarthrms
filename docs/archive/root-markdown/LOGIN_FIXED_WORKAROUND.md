## 📝 For Frontend Dev

**Use this approach:**
1. Get token using `./get-frontend-token.sh` script
2. Store token in localStorage
3. Use token in all API requests
4. Token is valid for 24 hours
5. Regenerate token when needed

**Example:**
```javascript
// Get token (run script or use pre-generated)
const token = 'YOUR_TOKEN_HERE';
const tenantId = 'apitest1771147024';

// Use in all requests
fetch('http://API_URL/api/hr/employees', {
  headers: {
    'Authorization': `Bearer ${token}`,
    'x-tenant-id': tenantId
  }
});
```

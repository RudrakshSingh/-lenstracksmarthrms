═══════════════════════════════════════════════════════════════════════════════
                         DATA FLOW (Request Lifecycle)
═══════════════════════════════════════════════════════════════════════════════

1. CLIENT REQUEST
   │
   │ POST https://api.etelios.com/api/auth/login
   │ { "email": "user@example.com", "password": "***" }
   │
   ▼
2. NGINX INGRESS
   │
   │ - SSL Termination
   │ - Rate Limiting Check (100 req/min)
   │ - Path Matching: /api/auth/* → auth-service:3001
   │
   ▼
3. AUTH-SERVICE POD
   │
   │ - Validate credentials
   │ - Query MongoDB (auth_db)
   │ - Generate JWT token
   │ - Cache session in Redis
   │
   ▼
4. RESPONSE
   │
   │ { "token": "eyJhbGc...", "user": {...} }
   │
   ▼
5. CLIENT STORES TOKEN
   │
   │ Subsequent requests include: Authorization: Bearer <token>
   │
   ▼
6. AUTHENTICATED REQUEST
   │
   │ GET https://api.etelios.com/api/hr/employees
   │ Headers: Authorization: Bearer eyJhbGc...
   │
   ▼
7. NGINX INGRESS
   │
   │ - Path: /api/hr/* → hr-service:3002
   │
   ▼
8. HR-SERVICE POD
   │
   │ - Validate JWT (local validation, no auth-service call)
   │ - Query MongoDB (hr-database)
   │ - Return employee data
   │
   ▼
9. RESPONSE
   │
   │ { "employees": [...] }
   │
   ▼
10. CLIENT RECEIVES DATA
